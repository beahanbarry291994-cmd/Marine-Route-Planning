# Marine Route Planning — 智能航海航线规划系统

基于 A* 路径规划与 KT 运动模型的船舶航线规划 Web 仿真平台，支持卫星地图可视化、PID 航向控制、多环境扰动模拟、AI 智能航行分析。

## 系统预览

### 路线概览
![路线概览](screenshot_overview.png)

卫星底图 + A* 全局路径 + KT 模型仿真轨迹 + 航路点标记。支持点击地图选取起终点和轨迹回放。

### 运动曲线
![运动曲线](screenshot_motion.png)

四象限实时曲线：舵角响应、航向跟踪（含期望航向）、航速变化、漂角分析。红色虚线标注最大舵角限幅。

### 栅格地图
![栅格地图](screenshot_grid.png)

二值栅格化处理结果（白=可航水域，黑=陆地/障碍），叠加规划路径与仿真轨迹。

### 数据摘要
![数据摘要](screenshot_summary.png)

仿真指标卡片 + AI 航行分析面板。支持 5 种分析类型：综合分析、航线评估、操纵控制、环境影响、风险优化。

## 功能特性

- **A\* 全局路径规划** — 基于卫星地图栅格化的最优航线搜索
- **KT 运动模型仿真** — 野本谦作 Nomoto 模型 + PID 航向控制 + 风/流环境扰动
- **交互式地图** — Plotly.js 卫星底图，支持缩放、平移、点击选点
- **多船型预设** — 散货船 / 油轮 / 集装箱船 / 客船 / 拖船
- **环境模拟** — 风速风向、流速流向、波浪参数独立配置
- **轨迹回放** — 时间轴播放控制，实时航速/航向/舵角显示
- **AI 航行分析** — DeepSeek 大模型驱动，5 种分析视角，对话式交互
- **中英文双语** — 完整 i18n 支持，一键切换
- **数据导出** — JSON 格式仿真报告导出

### 算法流程

1. **地图获取** — 从 CartoDB 下载卫星瓦片，拼接为完整地图
2. **栅格化** — OTSU 二值化 + 形态学处理 + 连通域分析（保留最大水域）
3. **A\* 寻路** — 8 方向搜索，欧几里得启发函数
4. **B-spline 平滑** — scipy splprep/splev 参数化平滑
5. **航路点提取** — 按设定间隔沿路径采样
6. **KT 运动仿真** — 4 阶 Runge-Kutta (odeint) 积分 + PID 航向控制
7. **环境扰动** — 风力侧向力 + 海流速度叠加

### KT 模型

船舶操纵运动采用一阶 Nomoto 模型：

$$\dot{r} = \frac{K \delta - (1 + a|r|)r}{T}$$

其中 K 为回转性指数，T 为追随性指数，a 为非线性修正系数。

## 参数说明

| 类别 | 参数 | 默认值 | 说明 |
|------|------|--------|------|
| 船舶 | K / T / a | 0.5 / 1.0 / 0.4 | KT 模型参数 |
| 船舶 | 船长 / 船宽 | 160m / 21m | 用于风力计算 |
| 船舶 | 航速 | 10 kn | 设计航速 |
| 航线 | 缩放级别 | 13 | 地图瓦片 zoom |
| 航线 | 安全距离 | 3 px | 陆地膨胀半径 |
| 环境 | 风速 / 风向 | 5 m/s / 45° | 影响侧向力 |
| 环境 | 流速 / 流向 | 0.5 m/s / 0° | 速度矢量叠加 |
| 控制 | KP / KI / KD | 1.0 / 0.01 / 5.0 | PID 航向控制 |
| 控制 | 最大舵角 | 35° | 舵角限幅 |
| 仿真 | 航路点间隔 | 500 m | 路径采样间距 |
